# 财务大表映射指引（给需求方）

> 配套文件：[`ledger-workbook.xlsx`](ledger-workbook.xlsx)
>
> 已按您提供的台账/送货单/出库退供表，以及 **Temu、速卖通全托管为主** 的模式改过一版。
> 表名尽量跟您现在 Excel 底部那些标签一致：**提货、出库、退供、提现、支出、工资**。

---

## 一、先说清楚：全托管下「钱」和「货」怎么走

和自己发货给买家不同，全托管大致是：

```text
工厂送货 → 您质检/分装/装袋 → 送到 Temu/速卖通仓
                              ↓
                     平台卖货、发货、售后
                              ↓
                     平台结算 → 您「提现」到账
                              ↓
              卖不掉/质检不合格 → 「退供」退回您
```

所以：

- **提货** = 货怎么进来、花了多少（含袋子）
- **出库** = 货怎么送给平台仓 / TK自营发出 / 代发厂发出（多数时候**还不是收入**）
- **退供** = 平台把货退回来（全托管特别重要，单独一张表）
- **提现** = 钱真正进口袋（全托管的主收入）
- **支出** = 房租、运费、杂费等花钱
- **工资与代发** = 员工计件、外包代发结算

**记住：全托管下，「出库」不等于「卖了」；「提现」才接近「收到货款」。**

## 二、六张大表各管什么

| 大表 | 一句话 | 您现在大概在哪 |
|------|--------|----------------|
| **商品档案** | 货号、几件装、尺码、大码是否加价 | 散落在各表品名里 |
| **提货明细** | 从哪个厂进了多少、什么价、袋子多少钱 | 「提货明细」「初步汇总」「手写送货单」 |
| **出库明细** | 送给 Temu/速卖通仓、TK自营出库、代发出库 | 「8月速卖通」「TK自营出库」「欣巧儿代发」 |
| **退供明细** | 平台退回来多少 | 「退供TEMU」「速卖通退供」 |
| **提现明细** | 平台打到账上多少钱 | 「提现」「提现总额」 |
| **支出明细** | 其他花钱 | 「支出」「支出明细」 |
| **工资与代发** | 员工计件、代发厂结算 | 「工资表」、代发页合计行 |

另有一张说明页。黄色行是例子，看懂可删。

## 三、日常工作怎么对号入座

| 您平时在做的事 | 填哪张表 |
|----------------|----------|
| 收到工厂送货单 / 手写单 / 对账 Excel | **提货明细**（按尺码拆行，或先按您习惯的矩阵再展开） |
| 付货款、定金 | **支出明细**（类别=采购付款）+ 提货单上可标付款状态 |
| 买包装袋、吊牌 | 能跟批次走的进 **提货明细** 的袋子字段；单独买的进 **支出明细** |
| 质检、分装、装袋，员工报数 | **工资与代发** |
| 货交给欣巧儿等代发 | **出库明细**（类型=代发出库）+ 结算进 **工资与代发** |
| 送货到 Temu / 速卖通仓库 | **出库明细**（类型=Temu送仓 / 速卖通送仓） |
| TK 自营发出 | **出库明细**（类型=TK自营出库） |
| 平台退货退供回来 | **退供明细**（不要只写在出库备注里） |
| 平台提现到银行卡/支付宝 | **提现明细** |
| 付运费、房租、杂费 | **支出明细** |
| 新开货号 / 改件装数 | **商品档案** |

对不上的先丢进支出明细，类别选「其他」，备注写清。**先别自己新开一堆表。**

## 四、和您现有表格习惯怎么兼容

从您给的表里，我们看到三个必须保留的习惯：

1. **按尺码记数量（XS~3XL）**  
   标准大表建议「一行一个货号+一个尺码」（方便以后 AI 汇总）。您现在爱用的「一行里横排 XS S M L…」矩阵，过渡期可以继续用，但请保证能展开成「分码一行」。

2. **包数 × 件装数 = 件数**  
   例如 6件装 × 17包 = 102件。三列都要能留下，不能只留一个「数量」。

3. **大码常常更贵、袋子单独计价**  
   同货号可以有多个单价；袋子规格（如 20×30）和袋子单价（如 0.145）进提货成本。

手写送货单常不写金额——没问题，金额空着，后续用台账价补；**不要为了填满去猜。**

---

## 五、只守 6 条规矩

1. 一行只记一件事（一个货号 + 一个尺码 + 一次进出）。
2. 货号写法固定，以商品档案为准（3031# 和 3031 不要混用）。
3. 日期用 `2026-08-03` 这种格式。
4. 金额只写数字；币种默认人民币，提现若是原币请注明。
5. 有原始单就填「原始凭证」文件名（如送货单编号 26109739）。
6. 不确定就空着，不要猜。

## 六、请您本周这样用

1. 先花 20 分钟填「商品档案」：常卖货号、几件装、常见尺码、大码是否加价。
2. 选最近一个月，按六张表把现有 Excel **对着搬**（不必一次完美）。
3. 搬的时候记下：哪些列没用、哪些您有我们没有、代发工序您怎么叫。
4. 发回来我们改字段，再谈 AI 自动填表。

## 七、请您确认的问题

1. 「东棠 / 风棠 / 森风棠」是自家店铺/主体，还是批发客户？
2. Temu 与速卖通全托管大约各占出货比例多少？TK 自营大概占多少？
3. 平台是否还有「余额内扣广告/罚金/仓储」？若有，是否希望从提现里拆开看？
4. 代发（如欣巧儿）是按件结加工费，还是整批卖断给对方？
5. 退供回来的货，通常是再送仓、转卖，还是报损？
6. 月底最想先看清的是：还欠厂里多少钱、平台还该结多少、还是每款赚不赚钱？

## 八、和后续 AI 的关系

| 阶段 | 做什么 |
|------|--------|
| 现在 | 大表对齐您现有账本语言 + 日常映射 |
| 下一步 | 手写送货单 / 台账 Excel → 自动进「提货明细」 |
| 再下一步 | 出库、退供、提现流水接入 |
| 最终 | 月底一键：成本、退供损失、提现收入、应付工资/代发 |

全托管场景下，AI 优先吃三样：**手写送货单、提货/出库 Excel、提现与退供记录**。表定稳之前不急着上全自动。
